### 网络故障处置
- 现象：`git push` 报 `CONNECT tunnel failed, response 502` / `SSL_read unexpected eof`。
- 原因：环境强制走本地代理 `HTTP_PROXY=http://127.0.0.1:56618`，该代理当时连不上 github.com（api.github.com 正常）。
- 直连（`env -u HTTP_PROXY ...`）也不通 —— 必须走代理。
- 解决：改用 SSH 推送（SSH 不受该代理影响）：
  `GIT_SSH_COMMAND="ssh -i ~/.ssh/github_ganui -o IdentitiesOnly=yes -o StrictHostKeyChecking=no" git push git@github.com:ganuidjskd11-afk/xzgaiji.git main`
- 密钥：`~/.ssh/github_ganui`（ed25519，注释 ganuidjskd11-afk@workbuddy），认证正常。
- 待办：可考虑把 remote 永久改成 SSH，避免代理抖动。
